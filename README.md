## 1. 프로젝트 개요

Valve사의 퍼즐 플랫포머 게임 'Portal'을 모작하여, 공간 왜곡 포탈 시스템과 다양한 퍼즐 메커니즘을 구현한 프로젝트입니다.

### 📝 프로젝트 정보

-   **개발 인원**: 1인
-   **개발 기간**: 약 2주 (총 18일, 2025.04.13 ~ 2025.04.30)
-   **개발 환경**: Unity 2022.3.62f

### 🏛️ 시스템 구조

프로젝트는 플레이어, 포탈, 퍼즐 기믹 등 각 시스템이 독립적으로 작동하면서도 유기적으로 상호작용하도록 설계되었습니다. 각 시스템은 명확한 역할을 가집니다.

## 2. Player System

### ✨ IK 시스템 (Inverse Kinematics)

플레이어 캐릭터의 자연스러운 움직임을 구현하기 위해 **FinalIK** 에셋의 `Aim IK`를 사용했습니다. 이를 통해 플레이어의 시선과 팔의 움직임이 조준하는 방향을 자연스럽게 따라가도록 하여 게임의 몰입감을 높였습니다.

## 3. Portal System

### 🏛️ Portal System 구조

포탈 시스템은 포탈의 생성, 렌더링, 물리적 이동을 관리하는 핵심 시스템입니다. `PortalManager`가 전체 로직을 총괄하며, 각 포탈은 자신과 연결된 다른 포탈의 정보를 가지고 독립적으로 작동합니다.

### 🔑 주요 클래스 정리

-   **`PortalManager`**: 포탈 생성, 포탈 쌍 연결 및 관리를 담당하는 중앙 관리자 클래스입니다.
-   **`Portal`**: 개별 포탈의 동작을 정의하는 클래스로, 렌더링 텍스처와 카메라를 제어합니다.
-   **`PortalableObject`**: 포탈을 통과할 수 있는 모든 객체(플레이어, 큐브 등)에 부착되는 컴포넌트입니다.

### 🖼️ 포탈 건너편 렌더링

왜곡 없는 실시간 포탈 뷰를 위해, 각 포탈은 별도의 카메라와 렌더 텍스처를 가집니다. 플레이어 카메라의 위치와 회전을 기준으로 포탈 반대편의 뷰를 계산하여 렌더 텍스처에 그려냄으로써, 마치 다른 공간이 눈앞에 있는 것처럼 보이게 합니다.

-   [**포탈 렌더링 매트릭스 계산 (Portal Matrix Calculation)**](PortalMatrixCalculation.md)

### 🎨 그래픽 클론

객체가 포탈을 절반쯤 통과했을 때, 몸이 잘려 보이지 않고 자연스럽게 보이도록 '그래픽 클론'을 생성합니다. 클론은 원본 객체와 동일한 외형과 애니메이션을 가지며, 포탈 반대편에 위치하여 마치 하나의 객체가 공간을 넘어가는 것처럼 보이게 합니다.

### 🏃 포탈 이동 시 운동 보존

객체가 포탈을 통과할 때, 이동하던 속도와 방향(운동량)이 그대로 보존됩니다. 포탈의 입구와 출구의 상대적인 방향을 계산하여 객체의 속도를 변환함으로써, 중력의 영향을 받는 자유 낙하와 같은 물리 현상이 포탈을 넘어서도 일관성 있게 유지됩니다.

## 4. 퍼즐 기믹

### 🌉 다리 설치 기믹

플레이어는 특정 지점에 에너지 다리를 생성하여 길을 만들 수 있습니다. 다리는 플레이어와 물체가 지나갈 수 있는 발판 역할을 하며, 퍼즐 해결의 핵심 요소로 사용됩니다.

### 🎨 페인트볼 기믹

**Paint in 3D** 에셋을 활용하여 특정 색상의 페인트볼을 발사하고, 벽이나 바닥에 칠해 특수한 효과를 발동시키는 기믹입니다. 예를 들어, 특정 색상의 바닥 위에서만 점프가 가능해지는 등의 규칙을 만들 수 있습니다.

### 🔘 버튼 기믹

맵 곳곳에 배치된 버튼은 플레이어나 특정 물체(예: 큐브)를 올려놓으면 활성화됩니다. 버튼을 누르면 문이 열리거나 다리가 생성되는 등 다른 시스템과 상호작용하여 퍼즐을 풀어나가는 데 사용됩니다.

## 5. UX 개선 시도

### 🎬 자연스러운 씬 전환 시도

레벨과 레벨 사이를 이동할 때, 단순한 로딩 화면 대신 포탈을 통과하는 연출을 사용했습니다. 플레이어가 출구 포탈로 들어가면, '더미 스테이지'라는 중간 공간을 거쳐 다음 레벨로 자연스럽게 넘어가도록 구현하여 끊김 없는 플레이 경험을 제공하고자 했습니다.
