# 3D 포탈 프로젝트

## 1. 개요

밸브사의 퍼즐 플랫포머 게임인 포탈에 대한 모작입니다.

개발 인원 : 1인
개발 기간 : 약 2주(총 18일) 2025.04.13 ~ 2025.04.30

개발 환경
- Unity 2022.3.62f

## 2. 사용 에셋

### FinalIK
- **IK(Inverse Kinematics)** : 피규어의 움직임을 자연스럽게 제어하기 위해 FinalIK의 Aim IK를 사용했습니다.

### Paint in 3D
- **퍼즐 색갈 기믹** : 일부 바닥 색을 이용한 기믹을 구현하기 위해 Paint in 3D 에셋을 사용했습니다.

## 3. 주요 기능

### 포탈
- **포탈 생성** : 플레이어가 포탈 건을 사용해 벽면에 포탈을 생성할 수 있습니다.
- **포탈 이동** : 플레이어와 일부 물체가 포탈을 통해 운동을 유지하며 공간을 이동할 수 있습니다.
- **포탈 시야** : 포탈을 통해 건너편 다른 공간을 실시간으로 볼 수 있습니다.

## 4. 효과 (Effect)

### 화면 전환 효과
- **더미 스테이지** : 더미 스테이지를 이용해 화면 전환 시 포탈을 통과하며 씬을 전환할 때 자연스럽도록 구현 했습니다.
